# 🌐 Portfólio Pessoal

## 📖 Sobre o Projeto

Este projeto foi a primeira versão do meu portfólio pessoal, desenvolvido com o objetivo de apresentar meus projetos, habilidades e trajetória acadêmica na área de tecnologia.

A aplicação foi construída utilizando **HTML**, **CSS** e **Node.js com Express**, servindo como uma plataforma para centralizar informações profissionais e disponibilizar meus principais trabalhos de forma organizada e acessível.

O projeto contribuiu para o desenvolvimento de conhecimentos em estruturação de páginas web, estilização responsiva, criação de rotas no backend e publicação de aplicações web.

## ✨ Funcionalidades

- 👨‍💻 Apresentação profissional
- 📂 Exibição de projetos desenvolvidos
- 🛠️ Listagem de habilidades técnicas
- 📄 Informações acadêmicas e profissionais
- 📱 Interface responsiva
- 📬 Área para contato

## 🛠️ Tecnologias Utilizadas

### Frontend
- 🌐 HTML5
- 🎨 CSS3

### Backend
- 🚀 Node.js
- ⚡ Express.js

## 🎯 Objetivo

O objetivo deste projeto foi criar uma presença profissional na web, reunindo informações sobre minha formação, experiências e projetos em um único ambiente, além de praticar conceitos fundamentais de desenvolvimento web full-stack.

## 📚 Aprendizados

- 🌐 Estruturação de páginas com HTML
- 🎨 Estilização e responsividade com CSS
- 🚀 Desenvolvimento backend com Express
- 🔗 Criação e gerenciamento de rotas
- 📦 Organização de projetos web
- ☁️ Publicação de aplicações

## 🚀 Evolução

Este projeto representa uma etapa importante da minha evolução como desenvolvedor, servindo como base para versões mais modernas do portfólio utilizando tecnologias como React, Tailwind CSS e APIs integradas.
